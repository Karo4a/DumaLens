   переменная окружения сеанса.

## Финальное ревью решения (Э10)

Метод: ревью всего репо — механическое
сканирование (`--all --json`, 90 кандидатов), разбор по слоям, граф зависимостей
проектов, `dotnet list package --vulnerable --include-transitive`, гейт.

### Найдено и исправлено

1. **Таймаут Api ронял цепь Blazor (средний, класс).** Все точки вызова Api
   в Web ловили `ApiException`/`HttpRequestException`, но не `TaskCanceledException`
   (таймаут HttpClient, 100 с по умолчанию): при зависании Api необработанное
   исключение в `async void OnLocationChanged`/lifecycle разрушает цепь.
   Тот же класс, что находка 47 ревью Э9 (исправлена тогда только в
   `AuthDelegatingHandler`). Фикс классом: `catch (TaskCanceledException)`
   с той же деградацией добавлен во все 20 блоков страниц/сервисов Web
   + `NavMenu.LogoutAsync` (там не ловился и `HttpRequestException`).
   Регрессы: `Home_ApiTimeout`, `Search_ApiTimeout`, `VoteCard_ApiTimeout`
   (PageRenderTests), `UserStateInitializerTests` (таймаут не затирает токены;
   отказ по статусу — затирает). RED подтверждён (4 падения до фикса).
2. **System.Text.Json 8.0.4 — CVE-2024-43485 (High, DoS).** Транзитивно через
   bunit в Web.Tests. Фикс: транзитивный пин `System.Text.Json 8.0.6`
   (Directory.Packages.props, `CentralPackageTransitivePinningEnabled`).
   Повторный `dotnet list package --vulnerable` — чисто.
3. **Docs/08: SQL отката int-ключей использовал `"Source" = 1`.** Колонка
   `Votes.Source` хранит строковые токены (`HasConversion<string>()`,
   `'Archive'`/`'Site'`) — запрос отката не выполнился бы. Исправлено на
   `"Source" = 'Site'` с пояснением.

### Принятые риски (осознанные решения)

- **AutoMapper 12.0.1** — 3 advisories High (GHSA-rvv3-g6hj-g44x,
  GHSA-gpwp-5797-mjff, GHSA-6vhm-j9h7-f9gh): DoS через неограниченную рекурсию
  при маппинге глубоко вложенных графов. Патчи только в 15.1.4+/16.3.0+
  (линейка 15+ — коммерческая лицензия; 13/14 не патчены и ломают API).
  Пин `[12.0.1]` — решение Э0 (эталон DocumentGenerator). Экспозиция DumaLens:
  маппинг только плоских внутренних DTO (запрос → сервисная модель → проекция),
  графы объектов из внешнего ввода недостижимы — риск принят, подавлен
  `NuGetAuditSuppress` (Directory.Build.props). Пересмотр — при смене лицензии
  AutoMapper или появлении пользовательских графов в маппинге.

### Ложные срабатывания сканирования (калибровка)

- `dbmodel-to-entity` ×10 (AuthService/UserService) — обратный маппинг полной
  проекции `UserDbModel`/`RefreshTokenDbModel` → сущность (паттерн Э9, аудит
  не теряется; проверено ревью Э9).
- `missing-summary` ×74 — приватный вложенный `QuarantineSums` (7) и методы
  тестов (67); конвенция summary и CS1591 относятся к public production-коду.
- `braces` ×2 — многострочные условия со скобками (TitleNormalizer,
  VoteParseValidator; класс ложного срабатывания из ревью Э3).
- `connection-string` — плейсхолдер `CHANGE_ME` дизайн-тайм фабрики (О-7).
- `hardcoded-origin` — CORS из конфигурации `Cors:AllowedOrigins` с fallback.
- `getall-in-service` — `BuildFactionIndex`: справочник фракций (25 записей)
  для разрешения токенов, осознанно (Э5); кандидат на кэш при росте нагрузки.
- `async-void` — `Search.OnLocationChanged`: обработчик события навигации,
  внутренние пути защищены (TryParse разбора URL, catch в RunSearch;
  таймаут закрыт находкой 1).

- Граф зависимостей 29 проектов: обратных ссылок нет; Web → Api.Client +
