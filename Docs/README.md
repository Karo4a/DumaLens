# DumaLens — документация проекта

Поисковая система и аналитическое приложение по законопроектам и голосованиям Государственной Думы РФ: первичные данные — архив за 1994–2024 годы (до 13.03.2024), пополнение до наших дней — с живого сайта vote.duma.gov.ru.

Статус этапа: **реализация MVP**. Выполнены Э0–Э9: каркас, модель данных и справочники, нормализация и парсеры, импорт полного архива, агрегаты фракций, поиск голосований, REST API и карточки, кроулер живого сайта, веб-интерфейс, аутентификация и роли (приёмки — [09-e5-acceptance.md](09-e5-acceptance.md), [10-e6-acceptance.md](10-e6-acceptance.md), [11-e7-acceptance.md](11-e7-acceptance.md); стиль и компоновка UI — [12-e8-ui.md](12-e8-ui.md); аутентификация и роли — [13-e9-auth.md](13-e9-auth.md), приёмка Э9 — [14-e9-acceptance.md](14-e9-acceptance.md)). Далее: производительность и развёртывание (Э10). В этом каталоге — ТЗ, функциональность, архитектура, план реализации и отчёты приёмки.

## Ключевые решения (кратко)

- Стек: **ASP.NET Core, .NET 8, C#**, Visual Studio 2022.
- База данных: **PostgreSQL 16+** + EF Core 8 (Npgsql). Полнотекстовый поиск — средствами PostgreSQL, без отдельного поискового движка на MVP.
- Архитектура и стиль кода — по проектам-ориентирам **Specular** (приоритетный) и **DocumentGenerator** (ветка master). **Два хоста: `DumaLens.Api` (REST) + `DumaLens.Web` (Blazor Server-фронтенд)**; Web ходит в Api только по HTTP через NSwag-клиент.
- Данные: исторический архив [data-dumaGovRu/vote](https://github.com/data-dumaGovRu/vote) (102 320 голосований, 1994 – 13.03.2024) + кроулер живого сайта `vote.duma.gov.ru` — пополнение до наших дней (включая IX созыв).
- Главная аналитическая функция — поиск голосований по **позициям фракций с настраиваемыми порогами и базой расчёта процента** (например: «НЛ — ЗА ≥ 70%, КПРФ — ПРОТИВ ≥ 50%»).
- **Роли и доступ (база)**: Пользователь / Модератор / Администратор, аутентификация JWT + refresh, пароли PBKDF2 (≥ 100 000 итераций) — [07-security.md](07-security.md); реализовано на Э9 ([13-e9-auth.md](13-e9-auth.md)), до тегов.
- Строка подключения — только через переменную окружения / user-secrets, в репозиторий не попадает (О-7).

## Источники данных

- Репозиторий [data-dumaGovRu/vote](https://github.com/data-dumaGovRu/vote) — открытые данные голосований (`vote-master.zip` — ZIP-архив репозитория).
- Живой сайт [vote.duma.gov.ru](http://vote.duma.gov.ru) — листинги и карточки голосований всех созывов.
- Эталон стиля и архитектуры: **DocumentGenerator** ([Karo4a/DocumentGenerator](https://github.com/Karo4a/DocumentGenerator), ветка master) и проект **Specular**.
